Create a protected room

The Safe Mode bot creates the room, so nobody can remove it, and sets it up correctly: end-to-end encrypted, invite-only, joined history. Invited people accept in their own client; members can then invite others.

Protect an existing room

Only rooms the Safe Mode bot created can be protected. The room must be end-to-end encrypted, invite-only and set to joined history. A room created by a person is refused.

Check protected rooms

Reads each protected room now and reports anything that would stop Safe Mode from working.
