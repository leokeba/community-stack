1. Link a WhatsApp account

Press Start QR linking, then on your phone open WhatsApp → Settings → Linked devices → Link a device and scan the code shown here. The code expires quickly; start again if it does.

The linked session belongs to the stack's own admin account on Matrix, not to a person. Keep the server private, and unlink the device in WhatsApp if you retire the bridge.

2. Choose a WhatsApp group

Only add a group intended for public announcements. This joins the linked WhatsApp account to the group and creates its Matrix portal. The invite link is removed from the bridge command chat after processing; revoke it in WhatsApp after use if possible.

After adding a group, copy its Matrix room ID from the Bridged rooms table below. Save it as the WhatsApp destination on the Channels page, then invite the announcements account to the portal room.

Mautrix WhatsApp is an unofficial, bidirectional bridge: messages in a bridged group also appear in Matrix. Only bridge a group intended for this purpose, and tell its members first. Bridged messages are readable by the server operator, so do not claim end-to-end encryption across WhatsApp.
