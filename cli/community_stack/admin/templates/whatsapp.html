WhatsApp setup

Connect an optional, unofficial WhatsApp bridge to send published announcements into a WhatsApp group.

Before you start

  • Bridge enabled: {{ "Yes" if bridge_enabled else "No" }}{% if not bridge_enabled %} — enable WhatsApp on the Services page. The server creates its private appservice credentials and registers the bridge with Matrix.{% endif %}
  • Matrix announcements account connected: {{ "Yes" if matrix_connected else "No" }}{% if not matrix_connected %} — connect one on the Channels page.{% endif %}
  • WhatsApp destination saved: {{ "Yes" if channel_connected else "No" }}

Link WhatsApp

  1. Sign in to Element using an account on {{ matrix_domain }}.
  2. Open a direct chat with @whatsappbot:{{ matrix_domain }}. If Element asks, start a chat with that user.
  3. Send login qr to the bridge bot.
  4. On your phone, open WhatsApp → Linked devices → Link a device, then scan the QR code shown in Element.

The bridge stores a linked-device session on this server. Keep the server private and unlink the device from WhatsApp if you disable or retire the bridge.

Choose the announcement group

  1. In Element, use the bridge bot's help to bridge the intended WhatsApp group to a Matrix portal room.
  2. Make the announcements account a member of that portal room. Keep encryption off: this connector cannot send encrypted Matrix events.
  3. On the Channels page, open WhatsApp announcements and save the portal room's Matrix room ID (it begins with !).
  4. Use Test connection. It checks that the announcements account can access the portal room; it cannot confirm the phone is still linked.

Mautrix WhatsApp is an unofficial, bidirectional bridge: messages in a bridged group may also appear in Matrix. Use a group intended for public announcements, and tell its members before bridging it. Publishing to this channel sends only canonical announcements, but does not make the bridge itself one-way.
